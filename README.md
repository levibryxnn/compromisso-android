# COMPROMISSO — Android

Aplicativo Android local-first, gratuito e open source para bloqueio voluntário de domínios, com proteção por PIN da pessoa de confiança.

**Status:** importação da versão de desenvolvimento 0.1.4 em preparação. A engine atual é DNS-first e **não protege** contra todas as formas de contorno (DoH de terceiros, IP direto, IPv6, proxies). **Não usar como proteção garantida.** Não há APK validado em celular.

Este repositório será preenchido pelo workflow de importação, que executará testes, Android Lint e tentará gerar um APK experimental antes de disponibilizá-lo em *Actions → Artifacts*.
